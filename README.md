# FAA drone airspace map

Downloads public FAA drone-airspace data (LAANC grid, controlled and special use airspace,
national security restrictions, TFRs, stadium events, FRIAs) into one GeoPackage and shows it
on an interactive map. See `UAS_Data_Sources.docx` for every dataset and field used.

## Setup (Windows PowerShell)

    python -m venv .venv
    .venv\Scripts\python -m pip install -r requirements.txt

## Run

    # download data for an area (New York State shown); output goes to out\
    .venv\Scripts\python build_uas_layers.py --bbox -79.8,40.4,-71.8,45.1

    # interactive app (opens http://localhost:8501)
    .venv\Scripts\streamlit run uas_app.py

    # or a single shareable HTML file: out\uas_map.html
    .venv\Scripts\python make_uas_map.py --title "New York"

Refresh groups for scheduling: `--group fast` (TFRs, stadium events; every 5 min),
`--group daily` (security restrictions), `--group weekly` (everything else).

Optional: FAA NOTAM API keys from api.faa.gov in `FAA_NOTAM_CLIENT_ID` / `FAA_NOTAM_CLIENT_SECRET`.

`out/` is not committed: it is regenerated by the script and contains FAA contact fields.
